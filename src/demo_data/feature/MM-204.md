Add a `Union` field to `marshmallow.fields` for values that may have one of several shapes, e.g. an id that is either an int or a UUID, or a payload that is one of two nested schemas.

## API

```python
class Union(Field):
    default_error_messages = {
        "no_candidate": "Value {input!r} cannot be serialized by any candidate field.",
    }

    def __init__(self, candidates, *, dump_map=None, **kwargs): ...
```

- `candidates` is a non-empty sequence of field instances or field classes (classes are instantiated with no arguments). An empty sequence raises `ValueError("Union requires at least one candidate field.")`.
- `dump_map` is an optional mapping from Python type to a field instance or class, used to pick the field on dump.
- Export it in `fields.__all__`.
- Candidates and `dump_map` fields must be bound to the parent schema like `List.inner` and `Tuple.tuple_fields` are (`_bind_to_schema`, on deep copies), so that `Nested` candidates and per-schema formats work.

## Load
- Try each candidate's `deserialize(value, attr, data, **kwargs)` in order and return the first result that does not raise `ValidationError`.
- If all fail, raise `ValidationError` whose messages are a dict from candidate index to that candidate's messages: `{0: ["Not a valid integer."], 1: ["Not a valid UUID."]}`.
- Missing values, `None`, `required` and `allow_none` behave as for any field (the base `Field` handles them before candidates are tried).

## Dump
- `None` dumps as `None`.
- With `dump_map`: use the field of the first entry, in mapping order, for which `isinstance(value, type)` is true.
- Without `dump_map`, or with no matching entry: use the first candidate whose `serialize`/`_serialize` of the value does not raise (`ValueError`, `TypeError`, `AttributeError` or `ValidationError`).
- If nothing works, raise the `no_candidate` error (a `ValidationError`).

## Examples

```python
class S(Schema):
    ident = fields.Union([fields.Int(), fields.UUID()])
    payload = fields.Union([fields.Nested(CatSchema), fields.Nested(DogSchema)])
    when = fields.Union([fields.Date(), fields.DateTime()], dump_map={dt.datetime: fields.DateTime(), dt.date: fields.Date()})

S().load({"ident": "12"})["ident"]          # 12
S().load({"ident": "2f1b...uuid"})["ident"]  # UUID('2f1b...')
S().load({"ident": "nope"})                  # ValidationError: {"ident": {0: ["Not a valid integer."], 1: ["Not a valid UUID."]}}
S().dump({"when": dt.datetime(2024, 1, 2, 3, 4)})["when"]  # "2024-01-02T03:04:00"
S().dump({"when": dt.date(2024, 1, 2)})["when"]            # "2024-01-02"
```

Note that `dump_map` order matters: `datetime` is a subclass of `date`, so it is listed first.

## Done when
- `Union` lives in `src/marshmallow/fields.py`.
- Tests are added to `tests/test_fields.py` (or the serialization/deserialization test modules), covering candidate order, the error shape, `Nested` candidates, `dump_map`, and `no_candidate`.
