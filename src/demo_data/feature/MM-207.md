Add an `Interval` field to `marshmallow.fields` for a start/end pair, serialized as an object, e.g. a booking period `{"start": "2024-01-01", "end": "2024-01-05"}`.

## API

```python
class Interval(Field[tuple]):
    default_error_messages = {
        "invalid": "Not a valid interval.",
        "order": "Start must not be after end.",
        "empty": "Interval must not be empty.",
    }

    def __init__(self, inner, *, allow_empty: bool = False, **kwargs): ...
```

- `inner` is a field instance or class (classes are instantiated with no arguments) used for both ends. It is bound to the parent schema like `List.inner` (`_bind_to_schema`, on a deep copy), so per-schema formats apply.
- Export it in `fields.__all__`.

## Load (dict -> tuple)
- The input must be a mapping with exactly the keys `"start"` and `"end"`. Anything else raises `invalid`: not a mapping, a missing key, or an extra key.
- Each end is deserialized with `inner`. If either fails, raise `ValidationError({"start": [...], "end": [...]})`, with only the failing keys.
- Then:
  - `start > end` raises `order`;
  - `start == end` raises `empty` unless `allow_empty=True`.
- It returns the tuple `(start, end)`.

## Dump (tuple -> dict)
- The value is any 2-item sequence `(start, end)`, dumped as `{"start": inner(start), "end": inner(end)}`.
- `None` dumps as `None`.

## Examples

```python
class Booking(Schema):
    period = fields.Interval(fields.Date())
    hours = fields.Interval(fields.Int, allow_empty=True)

Booking().load({"period": {"start": "2024-01-01", "end": "2024-01-05"}})["period"]
# (date(2024, 1, 1), date(2024, 1, 5))
Booking().dump({"period": (date(2024, 1, 1), date(2024, 1, 5))})
# {"period": {"start": "2024-01-01", "end": "2024-01-05"}}
Booking().load({"period": {"start": "2024-01-05", "end": "2024-01-01"}})
# ValidationError: {"period": ["Start must not be after end."]}
Booking().load({"period": {"start": "x", "end": "2024-01-01"}})
# ValidationError: {"period": {"start": ["Not a valid date."]}}
Booking().load({"hours": {"start": 3, "end": 3}})["hours"]   # (3, 3)
Booking().load({"period": {"start": "2024-01-01"}})          # {"period": ["Not a valid interval."]}
```
