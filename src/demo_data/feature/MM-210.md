Add `Schema.json_schema()`, which describes a schema instance as a JSON Schema (draft 2020-12) document for API docs and client generation.

## API

```python
schema.json_schema() -> dict
```

It is an instance method, so `only`, `exclude` and the schema's data keys (including `key_case` from MM-203) are respected. It returns:

```python
{
    "$schema": "https://json-schema.org/draft/2020-12/schema",
    "title": "<schema class name>",
    "type": "object",
    "properties": {<data key>: <field schema>, ...},   # in field order, dump and load fields alike
    "required": [<data keys of required fields, in field order>],   # key omitted when empty
    "additionalProperties": False if unknown == RAISE else True,
}
```

## Field schemas
Use the most specific match:

| field | schema |
|---|---|
| `Integer` | `{"type": "integer"}` |
| `Float`, `Decimal`, other `Number`, `TimeDelta` | `{"type": "number"}` |
| `Boolean` | `{"type": "boolean"}` |
| `Email` | `{"type": "string", "format": "email"}` |
| `Url` | `{"type": "string", "format": "uri"}` |
| `UUID` | `{"type": "string", "format": "uuid"}` |
| `DateTime` (and subclasses) | `{"type": "string", "format": "date-time"}` |
| `Date` | `{"type": "string", "format": "date"}` |
| `Time` | `{"type": "string", "format": "time"}` |
| `Duration` (MM-202) | `{"type": "string", "format": "duration"}` |
| other `String` | `{"type": "string"}` |
| `Enum` | `{"enum": [member names]}`, or `{"enum": [member values]}` when `by_value` is set |
| `List(inner)` | `{"type": "array", "items": <inner schema>}` |
| `Tuple(fields)` | `{"type": "array", "prefixItems": [...], "minItems": n, "maxItems": n}` |
| `Dict`/`Mapping` | `{"type": "object"}`, plus `"additionalProperties": <values schema>` when `values` is set |
| `Nested(S)` | `S`'s `json_schema()` without its `"$schema"` key; wrapped as `{"type": "array", "items": ...}` when `many=True` |
| `Union` (MM-204) | `{"anyOf": [<candidate schemas>]}` |
| `Interval` (MM-207) | `{"type": "object", "properties": {"start": <inner>, "end": <inner>}, "required": ["start", "end"], "additionalProperties": False}` |
| `Masked` (MM-209) | `{"type": "string"}` |
| anything else (`Raw`, `Method`, `Function`, ...) | `{}` |

## Modifiers
Apply them in this order, on top of the field schema:
1. **Validators** in `field.validators`:

   | validator | adds |
   |---|---|
   | `Range` | `minimum`/`maximum`, or `exclusiveMinimum`/`exclusiveMaximum` when not inclusive |
   | `Length` | `minLength`/`maxLength` for `"type": "string"`, `minItems`/`maxItems` for `"type": "array"`. `equal` sets both. Ignored for other types. |
   | `OneOf` | `"enum": list(choices)` |
   | `Regexp` | `"pattern": regex.pattern` |
   | `Unique` (MM-201) | `"uniqueItems": True` |

   Other validators are ignored.
2. `metadata["description"]` adds `"description"`.
3. `dump_only` adds `"readOnly": True`, and `load_only` adds `"writeOnly": True`.
4. `allow_none`: if the schema has a string `"type"`, it becomes `[type, "null"]`. Otherwise the schema is wrapped as `{"anyOf": [<schema>, {"type": "null"}]}`.

## Example

```python
class UserSchema(Schema):
    id = fields.Int(dump_only=True)
    email = fields.Email(required=True)
    tags = fields.List(fields.Str(), validate=validate.Length(max=5))
    nick = fields.Str(allow_none=True, metadata={"description": "Shown name"})

UserSchema().json_schema() == {
    "$schema": "https://json-schema.org/draft/2020-12/schema",
    "title": "UserSchema",
    "type": "object",
    "properties": {
        "id": {"type": "integer", "readOnly": True},
        "email": {"type": "string", "format": "email"},
        "tags": {"type": "array", "items": {"type": "string"}, "maxItems": 5},
        "nick": {"type": ["string", "null"], "description": "Shown name"},
    },
    "required": ["email"],
    "additionalProperties": False,
}
```

## Done when
- The method lives on `Schema` in `src/marshmallow/schema.py`. The field mapping may live in a new module, `src/marshmallow/json_schema.py`.
- Tests are added in a new `tests/test_json_schema.py`.
