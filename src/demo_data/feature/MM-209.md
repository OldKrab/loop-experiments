Add a `Masked` field to `marshmallow.fields` for sensitive values that must load normally but dump only partially visible, e.g. card numbers and API tokens in admin views.

## API

```python
class Masked(Field):
    def __init__(self, inner=None, *, visible: int = 4, mask_char: str = "*", **kwargs): ...
```

- `inner` is a field instance or class, default `String()`. It is bound to the parent schema like `List.inner`.
- `visible` must be an `int` ≥ 0 (not a bool). Otherwise raise `ValueError("`visible` must be a non-negative integer.")`.
- `mask_char` must be a `str` of length 1. Otherwise raise `ValueError("`mask_char` must be a single character.")`.
- Export it in `fields.__all__`.

## Behaviour
- **Dump:** serialize with `inner`, convert the result with `str()`, then replace every character except the last `visible` with `mask_char`.
  - A string of length ≤ `visible` is masked completely.
  - `visible=0` masks everything.
  - `None` dumps as `None`.
- **Load:** delegated to `inner` unchanged. No masking on load, and inner validation errors pass through.

## Examples

```python
class Card(Schema):
    number = fields.Masked()
    token = fields.Masked(visible=2, mask_char="#")
    pin = fields.Masked(fields.Int(), visible=0)

Card().dump({"number": "4111111111111111", "token": "secret", "pin": 1234})
# {"number": "************1111", "token": "####et", "pin": "****"}
Card().dump({"number": "abc"})          # {"number": "***"}
Card().load({"number": "4111111111111111", "pin": "12"})   # {"number": "4111111111111111", "pin": 12}
Card().load({"pin": "x"})               # ValidationError: {"pin": ["Not a valid integer."]}
```

## Done when
- `Masked` lives in `src/marshmallow/fields.py`.
- Tests are added to the field test modules.
